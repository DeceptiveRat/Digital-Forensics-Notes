## 1. *Just-In-Time(JIT)* compilation
- compilation of code at runtime instead of before execution
- commonly bytecode translation to machine code
- a combination of *Ahead-Of-Time(AOT)* compilation and interpretation
- speed of compiled code + flexibility of interpretation + overhead of interpreter + overhead of compiling and linking
